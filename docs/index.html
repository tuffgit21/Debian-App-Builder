About Debian App Builder

Debian Packaging. Simplified.

Simplifying Debian Package Creation

Debian App Builder is an open-source project designed to simplify the creation of Debian packages .deb through an accessible graphical interface.

Built with Python and CustomTkinter, Debian App Builder aims to make Linux software packaging more approachable by helping developers organize application files and generate Debian packages without manually handling every step of the process.

Our Mission

Our mission is to make Debian packaging easier, more accessible, and more efficient for developers of all experience levels. Whether you're learning Linux development or preparing your own application for distribution, Debian App Builder aims to simplify your workflow.

Key Features

  • Debian Package Creation: Generate .deb packages for Debian-based Linux distributions.

  • Graphical Interface: Configure packages through a user-friendly GUI.

  • Package Organization: Help structure application files and package metadata correctly.

  • Desktop Integration: Support application icons and desktop entries.

  • Continuous Improvement: Ongoing development focused on reliability, usability, and packaging features.

Note:

Feature availability may vary between development versions.

Built for the Debian Ecosystem

Debian App Builder focuses on the Debian package format and the tools used throughout the Debian ecosystem. Generated packages must still meet their target system's architecture, dependency, and compatibility requirements.

Development

Debian App Builder is actively developed, with ongoing work focused on improving its interface, package-generation workflow, and overall reliability. Future development plans include expanding automation and command-line capabilities.

Open Source

Debian App Builder is developed under the tuffgit21 GitHub account. Explore the source code, follow development, report issues, or contribute through the project's GitHub repository.

Thank You

Thank you for checking out Debian App Builder and supporting independent software development. Every suggestion, bug report, and contribution helps the project improve. Build for Debian. Package with confidence.

Installation

Debian App Builder requires customtkinter + python3-tk + dpkg-dev on Debian/WSL.

# Install the stable release from APT repo
echo "deb [signed-by=/usr/share/keyrings/tuffgit21.gpg] https://tuffgit21.is-a.dev/tuffgit21-APT-repo stable main" | 
sudo tee /etc/apt/sources.list.d/tuffgit21.list
sudo apt update
sudo apt install debian-app-builder

Install Testing Version

testing

To install the latest Testing version, use the testing APT repository:

# Add the testing repository
echo "deb [signed-by=/usr/share/keyrings/tuffgit21.gpg] https://tuffgit21.is-a.dev/tuffgit21-APT-repo testing main" | sudo tee /etc/apt/sources.list.d/tuffgit21.list
sudo apt update

# Install the testing version
sudo apt install debian-app-builder/testing

# Or upgrade from stable to testing
sudo apt install -t testing debian-app-builder

Note: The testing version may contain newer features but could be less stable than the stable release. Always backup your work before installing testing versions.

How to Use

  1. Launch the app: Run debian-app-builder from your applications menu or terminal.
  2. Select input type: Choose Python app, C source code, or app folder.
  3. Configure metadata: Fill in Name, Version, Architecture, Dependencies, and Maintainer.
  4. Optional features: Enable .desktop categories, Terminal options, or vendor Python dependencies.
  5. Build: Click the Build button to generate your .deb package.
  6. Install: Use sudo dpkg -i your-package.deb or double-click the .deb file.
