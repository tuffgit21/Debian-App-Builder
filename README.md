# Debian-App-Builder

Debian-App-Builder is a GUI tool for scaffolding Debian (`.deb`) packages. It generates the folder structure, `control` file, launcher script, and `.desktop` entry from your Python or C app.

## Features

- Interactive GUI to create Debian `.deb` package scaffolding.   
- Automatic creation of the standard Debian directory structure.   
- Generation of the `control` file with basic package metadata.   
- Launcher script and `.desktop` entry generation for Python and C applications.
